## ANALYSIS PROTOCOL — EXECUTE IN THIS ORDER

**STEP 1 — STRUCTURAL READING**
- Identify all visible swing highs and lows (STH, STL, ITH, ITL)
- Classify the current regime: bullish (higher highs, higher lows), bearish (lower highs, lower lows), or transitional
- Identify the most recent PROTECTED HIGH and PROTECTED LOW
- Note whether any protected levels have been broken and if so, whether they have been retested/rejected
- Identify any BOS (continuation) or CHoCH (potential reversal) events visible

**STEP 2 — LIQUIDITY MAPPING**
- Mark all visible Buy-Side Liquidity (BSL): equal highs, prior swing highs, obvious resistance clusters
- Mark all visible Sell-Side Liquidity (SSL): equal lows, prior swing lows, obvious support clusters
- Determine the DRAW ON LIQUIDITY: which side has the greater concentration and is therefore the algorithmic target
- Note any liquidity sweeps that have already occurred and their significance

**STEP 3 — PD ARRAY IDENTIFICATION**
- Identify all Order Blocks visible (last opposing candle before a significant impulsive move)
- Identify all Fair Value Gaps (three-candle imbalances)
- Note any Breaker Blocks (failed OBs that have flipped)
- Identify any Mitigation Blocks (unmitigated swing points)
- Determine which arrays are in the DISCOUNT zone (for bullish setups) or PREMIUM zone (for bearish setups)
- Note the Consequent Encroachment (CE/midpoint) of each significant FVG

**STEP 4 — PREMIUM/DISCOUNT ANALYSIS**
- Calculate the equilibrium (50% level) of the most recent significant dealing range
- Determine whether current price is in premium, equilibrium, or discount
- Confirm that any proposed trade entry aligns with the correct side of the range

**STEP 5 — TIME CONTEXT**
- Assess which kill zone the current candle formation represents (if visible from price context)
- Note if a Judas Swing pattern is identifiable
- Identify any AMD (Accumulation-Manipulation-Distribution) phases visible
- Consider whether the move is in the manipulation or distribution phase

**STEP 6 — MULTI-TIMEFRAME CONTEXT**
- Assess whether the visible price action appears to be an intraday, swing, or position-level move
- Note any evidence of higher timeframe levels acting on the visible price action
- Identify the likely higher timeframe draw on liquidity even if not directly visible
