PART A - PSEUDO-CODE

# ---- STEP 1: BUILD THE SPREAD AND FIT THE OU PROCESS -----------------------
# The hedge ratio B is chosen to MAXIMISE THE OU LOG-LIKELIHOOD, not by OLS.
# That is a meaningful difference: OLS minimises residual variance, MLE picks
# the portfolio that behaves most like a mean-reverting process.

PROCEDURE fit_spread(S1, S2):
    FOR B in grid over [0, 1]:
        X_t(B) = (1/S1_0) * S1_t  -  (B/S2_0) * S2_t
        ell(B) = average OU log-likelihood of X(B)
    B* = argmax ell(B)
    theta, mu, sigma = MLE_OU( X(B*) )
    RETURN B*, theta, mu, sigma

# ---- STEP 2: VALIDATE THE OU ASSUMPTION (the paper's own check) ------------
# Simulate paths from the fitted parameters, refit by MLE, compare. If the
# process is genuinely OU the two parameter sets should agree.
PROCEDURE validate_ou(theta, mu, sigma, n):
    X_sim  = simulate_OU(theta, mu, sigma, n)
    theta2, mu2, sigma2 = MLE_OU(X_sim)
    # Expect theta and sigma to agree closely. EXPECT mu TO DISAGREE - in the
    # paper it moves by ~14% in BOTH pairs. Mean-reversion speed is the
    # weakest link and the bands depend on it most.

# ---- STEP 3: SOLVE THE OPTIMAL DOUBLE STOPPING PROBLEM ---------------------
# EXIT problem (given a position, when to liquidate):
#     V(x) = sup_tau  E_x[ e^{-r*tau} (X_tau - c) ]
#     Optimal rule: liquidate at the first time X_t >= b*
#
# ENTRY problem (when to open, or never):
#     J(x) = sup_nu   E_x[ e^{-rhat*nu} (V(X_nu) - X_nu - chat) ]
#
# The entry reward CONTAINS the exit value function. That nesting is what
# makes it a DOUBLE stopping problem, and it is the step ad-hoc threshold
# systems skip entirely.

PROCEDURE optimal_bands(theta, mu, sigma, r, c, stop_loss L = None):
    IF L is None:
        entry region = (-inf, a*]        # a half-line: enter when cheap enough
    ELSE:
        entry region = [d*, a*]          # a BOUNDED interval, strictly above L
        # Wait if X is too HIGH (above a*) OR too CLOSE TO THE STOP (below d*).
        # The wait region is DISCONNECTED. This is the paper's key structural
        # result and it inverts standard practice: past a point, a further
        # divergence is a WORSE trade, not a better one, because it is closer
        # to the stop than to reversion.
    exit level = b*                      # b* DECREASES as L increases
    RETURN d*, a*, b*

"""
OU parameter estimation, hedge-ratio selection by MLE, and numerical solution
of the optimal entry/exit bands.

Dependencies: numpy, scipy (optional - falls back to a grid search)

NOTE ON SCOPE: the paper solves the free-boundary problem analytically via the
classical F and G solutions of the OU differential equation. The
implementation here solves the same optimisation NUMERICALLY on a grid, which
is far simpler to verify and adequate for practical use. Use it to get the
bands; consult the paper for the analytic characterisation.
"""

import numpy as np


def ou_log_likelihood(x: np.ndarray, dt: float) -> tuple:
    """Exact MLE of an OU process from a discrete sample.

    dX = mu (theta - X) dt + sigma dB

    Uses the exact discrete transition (X is Gaussian AR(1) with
    b = exp(-mu*dt)), not an Euler approximation - the difference matters when
    mu*dt is not small, which is exactly the fast-reverting case of interest.

    Returns (theta, mu, sigma, avg_log_likelihood).
    """
    x = np.asarray(x, dtype=float)
    n = len(x) - 1
    if n < 3:
        return (np.nan,) * 4

    x0, x1 = x[:-1], x[1:]
    sx0, sx1 = x0.sum(), x1.sum()
    sx0x0, sx1x1, sx0x1 = (x0 * x0).sum(), (x1 * x1).sum(), (x0 * x1).sum()

    denom = n * (sx0x0 - sx0x1) - (sx0 ** 2 - sx0 * sx1)
    if abs(denom) < 1e-300:
        return (np.nan,) * 4
    theta = (sx1 * sx0x0 - sx0 * sx0x1) / denom

    num_b = sx0x1 - theta * (sx0 + sx1) + n * theta ** 2
    den_b = sx0x0 - 2.0 * theta * sx0 + n * theta ** 2
    if den_b <= 0:
        return (np.nan,) * 4
    b = num_b / den_b
    if not (0.0 < b < 1.0):
        return (np.nan,) * 4        # not mean-reverting on this sample

    mu = -np.log(b) / dt

    resid = x1 - x0 * b - theta * (1.0 - b)
    sigma_hat_sq = (resid @ resid) / n
    sigma = np.sqrt(sigma_hat_sq * 2.0 * mu / (1.0 - b ** 2))

    var_t = sigma_hat_sq
    ll = -0.5 * np.log(2 * np.pi) - 0.5 * np.log(var_t) - \
        (resid @ resid) / (2.0 * var_t * n)
    return float(theta), float(mu), float(sigma), float(ll)


def select_hedge_ratio(s1: np.ndarray, s2: np.ndarray, dt: float,
                       b_grid=None):
    """Choose B maximising the OU average log-likelihood (the paper's method).

    Portfolio: $1 in asset 1 against $B in asset 2, normalised by initial
    prices. NOTE this is NOT an OLS hedge ratio - it selects the portfolio
    that behaves most like an OU process, which is a different objective.
    """
    if b_grid is None:
        b_grid = np.linspace(0.01, 1.0, 100)
    best = (None, -np.inf, None)
    for B in b_grid:
        x = s1 / s1[0] - B * (s2 / s2[0])
        theta, mu, sigma, ll = ou_log_likelihood(x, dt)
        if np.isfinite(ll) and ll > best[1]:
            best = (float(B), float(ll), (theta, mu, sigma))
    return {"B": best[0], "avg_log_likelihood": best[1],
            "theta": best[2][0] if best[2] else np.nan,
            "mu": best[2][1] if best[2] else np.nan,
            "sigma": best[2][2] if best[2] else np.nan}


def simulate_ou(theta, mu, sigma, n, dt, x0=None, seed=None):
    """Exact-transition OU simulation (no Euler discretisation error)."""
    rng = np.random.default_rng(seed)
    b = np.exp(-mu * dt)
    sd = sigma * np.sqrt((1.0 - b ** 2) / (2.0 * mu))
    x = np.empty(n)
    x[0] = theta if x0 is None else x0
    for i in range(1, n):
        x[i] = theta + b * (x[i - 1] - theta) + sd * rng.standard_normal()
    return x


def validate_ou_fit(theta, mu, sigma, n, dt, seed=0) -> dict:
    """The paper's simulate-and-refit consistency check.

    Expect theta and sigma to round-trip closely and mu to be the weak link:
    in the paper mu moves ~14% in BOTH ETF pairs.
    """
    x = simulate_ou(theta, mu, sigma, n, dt, seed=seed)
    t2, m2, s2, _ = ou_log_likelihood(x, dt)
    return {
        "theta_empirical": theta, "theta_refit": t2,
        "mu_empirical": mu, "mu_refit": m2,
        "sigma_empirical": sigma, "sigma_refit": s2,
        "mu_pct_error": abs(m2 - mu) / mu * 100.0 if mu else np.nan,
    }


def optimal_exit_level(theta, mu, sigma, r, c, grid=None) -> float:
    """Optimal liquidation level b*: exit at the first time X_t >= b*.

    Solved numerically. For each candidate level b above the current state,
    the value of the 'wait until X hits b' policy is

        value(x; b) = (b - c) * E_x[ e^{-r * tau_b} ]

    For an OU process the Laplace transform of the first passage time is

        E_x[e^{-r tau_b}] = F(x) / F(b),   x <= b

    where F is the increasing solution of the OU ODE, expressible through the
    confluent hypergeometric function. We evaluate F by its integral
    representation, which is numerically stable for the parameter ranges that
    matter here.
    """
    if grid is None:
        grid = np.linspace(theta, theta + 6.0 * sigma / np.sqrt(2.0 * mu), 600)

    def F(x):
        # F(x) = INT_0^inf u^{r/mu - 1} exp( sqrt(2mu/sigma^2)(x-theta)u - u^2/2 ) du
        u = np.linspace(1e-6, 40.0, 4000)
        expo = (np.sqrt(2.0 * mu / sigma ** 2) * (x - theta) * u - u ** 2 / 2.0)
        expo = np.clip(expo, -700, 700)
        return np.trapezoid(u ** (r / mu - 1.0) * np.exp(expo), u)

    Fg = np.array([F(b) for b in grid])
    x_ref = theta
    Fx = F(x_ref)
    with np.errstate(divide="ignore", invalid="ignore"):
        value = (grid - c) * (Fx / Fg)
    value[~np.isfinite(value)] = -np.inf
    return float(grid[int(np.argmax(value))])


def optimal_entry_band(theta, mu, sigma, r, c, c_entry, b_star,
                       stop_loss=None, grid=None) -> dict:
    """Optimal entry region.

    Without a stop-loss the entry region is a half-line (-inf, a*].
    WITH a stop-loss it is a BOUNDED interval [d*, a*] strictly above the stop,
    because entering close to the stop carries a high probability of being
    stopped out before reversion.

    Numerical approach: the entry reward at level x is

        reward(x) = V(x) - x - c_entry

    where V(x) is the value of the position acquired. With a stop-loss, V is
    penalised by the probability of hitting the stop before the target, which
    for an OU process we estimate by simulation.
    """
    if grid is None:
        sd = sigma / np.sqrt(2.0 * mu)
        lo = theta - 4.0 * sd if stop_loss is None else stop_loss
        grid = np.linspace(lo, theta + 2.0 * sd, 200)

    rewards = []
    for x in grid:
        if stop_loss is not None and x <= stop_loss:
            rewards.append(-np.inf)
            continue
        p_target, disc = _hit_probability(x, b_star, stop_loss,
                                          theta, mu, sigma, r)
        # Value of the position acquired at x:
        #   - hit the target  -> receive b_star - c
        #   - hit the stop    -> receive stop_loss - c
        #   - neither, within the horizon -> the spread has reverted toward
        #     its long-run mean, so mark it at theta - c.
        # NOTE: marking the unresolved case at ZERO is a modelling error that
        # collapses V and makes the entry region vanish entirely. Found and
        # fixed during in-session testing.
        fallback = (stop_loss - c) if stop_loss is not None else (theta - c)
        V = disc * (p_target * (b_star - c) + (1.0 - p_target) * fallback)
        rewards.append(V - x - c_entry)

    rewards = np.array(rewards)
    positive = np.where(rewards > 0)[0]
    if len(positive) == 0:
        return {"enter": False, "d_star": None, "a_star": None,
                "b_star": b_star, "max_reward": float(np.nanmax(rewards))}

    return {
        "enter": True,
        "d_star": float(grid[positive[0]]),     # lower edge - ABOVE the stop
        "a_star": float(grid[positive[-1]]),    # upper edge
        "b_star": float(b_star),
        "best_entry": float(grid[int(np.argmax(rewards))]),
        "max_reward": float(np.max(rewards)),
    }


def _hit_probability(x, target, stop, theta, mu, sigma, r,
                     n_paths=2000, horizon_years=2.0, seed=0):
    """P(hit target before stop) and the expected discount factor, by simulation."""
    rng = np.random.default_rng(seed)
    dt = 1.0 / 252.0
    n_steps = int(horizon_years * 252)
    b = np.exp(-mu * dt)
    sd = sigma * np.sqrt((1.0 - b ** 2) / (2.0 * mu))

    paths = np.full(n_paths, float(x))
    hit_t = np.full(n_paths, np.nan)
    hit_target = np.zeros(n_paths, dtype=bool)
    alive = np.ones(n_paths, dtype=bool)

    for step in range(1, n_steps + 1):
        paths[alive] = (theta + b * (paths[alive] - theta)
                        + sd * rng.standard_normal(alive.sum()))
        done_t = alive & (paths >= target)
        hit_target[done_t] = True
        hit_t[done_t] = step * dt
        alive &= ~done_t
        if stop is not None:
            done_s = alive & (paths <= stop)
            hit_t[done_s] = step * dt
            alive &= ~done_s
        if not alive.any():
            break

    hit_t[np.isnan(hit_t)] = horizon_years
    return float(hit_target.mean()), float(np.mean(np.exp(-r * hit_t)))

# 33.8 against a true 12.0 on a 60-day window). The paper's own Table 1 refit
# coming in LOWER than its empirical estimate is a single draw from this very

#      0.555  0.5731     0.30     0.5558     0.5621          0.05

# BOTH STRUCTURAL RESULTS REPRODUCE:
#
#   (a) b* DECREASES MONOTONICALLY AS THE STOP RISES: 1.41 -> 1.09 -> 1.09
#       -> 0.94 -> 0.30 equilibrium sd. This is the paper's "a higher
#       stop-loss level always implies a lower optimal take-profit level".
#
#   (b) THE ENTRY REGION IS BOUNDED, and its lower edge sits ABOVE the stop
#       rather than at it. The band also NARROWS steadily as the stop rises
#       (width 0.0304 -> 0.0192 -> 0.0132 -> 0.0063), collapsing toward
#       nothing - the paper's "the optimal liquidation level decreases with
#       the stop-loss level until they coincide", at which point the trade is
#       not worth taking.
#
#   HONEST CAVEAT ON (b) - THE GAP ABOVE THE STOP IS NOT ESTABLISHED.
#   A second, higher-resolution run (2000 paths, finer grid) gives:
#
#        stop       b*   b*(sd)   entry lo   entry hi   (lo-stop)/sd
#        None   0.5951     1.60     0.5003     0.5891            --
#        0.540  0.5832     0.90     0.5403     0.5714          0.02
#        0.545  0.5815     0.80     0.5453     0.5681          0.02
#        0.550  0.5798     0.70     0.5503     0.5654          0.02
#        0.555  0.5798     0.70     0.5552     0.5646          0.01
#
#   The monotone decline in b* and the narrowing band reproduce robustly at
#   BOTH resolutions. But the measured gap between the stop and the entry
#   band's lower edge SHRANK from 0.05-0.06 sd (coarse) to 0.01-0.02 sd
#   (fine). A quantity that shrinks as the grid refines is the signature of a
#   discretisation artefact, not a real separation.
#
#   CONCLUSION: this simulation-on-a-grid approach CANNOT confirm the paper's
#   "entry region lies strictly above the stop-loss" result. It is consistent
#   with it and equally consistent with the boundary sitting AT the stop.
#   Confirming it requires the analytic free-boundary solution via the F and G
#   functions, which the paper provides and this code does not implement.
#
# ---- (3) A BUG WORTH KNOWING ABOUT -----------------------------------------
# The first implementation valued an unresolved position (target not reached
# within the horizon, no stop set) at ZERO. That collapses V and makes the
# entry region vanish entirely at every parameter setting. The fix is to mark
# the unresolved case at theta - c, since a mean-reverting spread that has
# not hit either barrier has reverted toward its long-run mean.
#
# Separately, an EARLIER version computed b* WITHOUT reference to the stop
# and then used it in the stopped problem. That produced b* = 2.82 sd, a
# target so far away that p(hit target before stop) fell to 0.16-0.20 and NO
# entry region existed at any level. That failure is itself an illustration
# of the paper's point: setting the stop and the target independently is
# incoherent, and the incoherence shows up as a strategy with no viable
# entry at all.

--------------------------------------------------------------------------------
PART D - PRACTICAL GUIDANCE AND PITFALLS
--------------------------------------------------------------------------------

1.  THREE TAKEAWAYS THAT DO NOT REQUIRE THE FULL SOLUTION.
    Even without implementing the free-boundary problem:
      (a) Set the stop and the target JOINTLY. A higher stop implies a LOWER
          optimal take-profit. Setting them independently is incoherent.
      (b) DO NOT ENTER NEAR YOUR STOP. The entry region is bounded BELOW as
          well as above. The trades closest to the stop - the ones a 2-sigma
          or s-score system takes most eagerly - are the ones the optimal
          policy declines.
      (c) VERIFY THE OU FIT FIRST, using simulate-and-refit. If the process
          is not OU, none of the bands mean anything.

2.  mu IS THE WEAKEST LINK. Mean-reversion speed round-tripped with a 10.3%
    error here and ~14% in the paper's own Table 1, against sub-1% errors for
    theta. The bands depend on mu most sensitively. Compute them across the
    plausible range of mu and check how far they move before trading them.

3.  MLE HEDGE RATIO != OLS HEDGE RATIO. select_hedge_ratio() maximises the OU
    log-likelihood, which selects the portfolio that behaves most like a
    mean-reverting process. OLS minimises residual variance. They give
    different B, and the paper's choice is the better-motivated one for this
    purpose.

4.  USE THE EXACT TRANSITION, NOT EULER. ou_log_likelihood() and simulate_ou()
    both use the exact Gaussian AR(1) transition with b = exp(-mu*dt). With
    fast mean reversion (mu = 33 means a half-life of about 5 trading days),
    mu*dt is not small and Euler discretisation introduces real bias.

5.  THE DISCOUNT RATE r IS A PREFERENCE, NOT AN OBSERVABLE. It is what makes
    waiting costly. Larger r means more eagerness to enter and exit. There is
    no market price for it; use your genuine opportunity cost of capital and
    check the sensitivity.

6.  SINGLE SPREAD ONLY. The framework optimises one spread in isolation. A
    real book holds many correlated spreads competing for capital, and
    nothing here addresses allocation across them.

7.  OPTIMAL BANDS ON A DEAD EDGE ARE STILL DEAD. Both parent entries are
    graded substantially-decayed. This entry improves HOW a convergence trade
    is executed; it does not restore an edge that has been competed away.
